Configuration Test Matrix for CMake Migration
==============================================

This document maps all autotools configuration options to CMake equivalents
and defines the test matrix for verifying binary equivalence.


AUTOTOOLS CONFIGURE OPTIONS
============================

From ./configure --help:

Feature Flags (--enable/--disable):
-----------------------------------
1. --disable-posix-timers
   Default: enabled (if supported by OS)
   Effect: Use interval timers instead of POSIX timers
   Define: PTPD_PTIMERS
   Source: eventtimer_posix.c vs eventtimer_itimer.c

2. --disable-pcap
   Default: enabled (if pcap-config found)
   Effect: Disable PCAP packet capture support
   Define: PTPD_PCAP
   
3. --disable-snmp
   Default: enabled (if net-snmp-config found)
   Effect: Disable SNMP monitoring support
   Define: PTPD_SNMP
   Source: dep/snmp.c

4. --enable-runtime-debug
   Default: disabled
   Effect: Enable all debug messages
   Define: RUNTIME_DEBUG
   Conflicts with: debug-level

5. --enable-debug-level={basic,medium,all}
   Default: none
   Effect: Set debug message level
   Defines:
     basic:  PTPD_DBG
     medium: PTPD_DBG2
     all:    PTPD_DBGV
   Conflicts with: runtime-debug

6. --disable-daemon
   Default: enabled
   Effect: Disable daemon mode
   Define: PTPD_NO_DAEMON

7. --enable-experimental-options
   Default: disabled
   Effect: Enable experimental features
   Define: PTPD_EXPERIMENTAL

8. --disable-statistics
   Default: enabled
   Effect: Disable realtime statistics
   Define: PTPD_STATISTICS
   Source: dep/statistics.c, dep/outlierfilter.c

9. --enable-sw-clock
   Default: disabled
   Effect: Enable software clock implementation
   Define: SW_CLOCK_ENABLED
   Source: dep/sw_clock/*.c (6 files)

10. --disable-so-timestamping
    Default: enabled (Linux only)
    Effect: Disable SO_TIMESTAMPING socket option
    Define: PTPD_DISABLE_SOTIMESTAMPING

11. --enable-slave-only
    Default: disabled
    Effect: Build slave-only version (cannot be master)
    Define: PTPD_SLAVE_ONLY


Package Options (--with/--without):
-----------------------------------
12. --with-pcap-config=<path>
    Default: search PATH
    Effect: Specify pcap-config location
    
13. --with-net-snmp-config=<path>
    Default: search PATH
    Effect: Specify net-snmp-config location

14. --with-max-unicast-destinations=<16-2048>
    Default: 128
    Effect: Set maximum unicast destinations
    Define: PTPD_UNICAST_MAX=<value>

====================

set(PCAP_CONFIG "" CACHE FILEPATH "Path to pcap-config")
set(NET_SNMP_CONFIG "" CACHE FILEPATH "Path to net-snmp-config")

VERIFICATION PROCEDURE FOR EACH CONFIG
=======================================

For each of the 16 configurations above:

1. Build with autotools:
   ./configure [options...]
   make clean && make
   cp src/ptpd2 /tmp/ptpd2-auto-config-<N>
   
2. Build with CMake:
   cmake -B build-test-<N> [options...]
   cmake --build build-test-<N>
   cp build-test-<N>/src/ptpd2 /tmp/ptpd2-cmake-config-<N>
   
3. Compare binaries:
   ./scripts/compare-binaries.sh \
     /tmp/ptpd2-auto-config-<N> \
     /tmp/ptpd2-cmake-config-<N> \
     > results/comparison-config-<N>.txt
     
4. Verify:
   - File size within 5% tolerance
   - Symbol count within 3%
   - Symbols functionally equivalent
   - Both binaries run successfully
   - --help and --version output match
   
5. Document results in results/test-matrix-results.txt
