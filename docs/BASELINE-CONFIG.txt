KEY DIFFERENCES
---------------
PCAP
  macOS only. iOS has no pcap support.

PTPD_IOS + PTPD_LIBRARY_MODE
  iOS only. Injected as CMAKE_C_FLAGS. Gate the library API
  (ptpd_init/start/shutdown) and iOS-specific code paths.
  Must be set for any build that uses ptpd as an embedded library.

ENABLE_DAEMON
  Only enabled for macOS Release. All other configurations run in foreground.

ENABLE_RUNTIME_DEBUG / DEBUG_LEVEL
  macOS Debug explicitly sets ENABLE_RUNTIME_DEBUG=ON and DEBUG_LEVEL=all.
  Due to the mutual exclusivity rule in Options.cmake, ENABLE_RUNTIME_DEBUG
  wins and DEBUG_LEVEL is silently forced to none at configure time.
  The effective macOS Debug binary has ENABLE_RUNTIME_DEBUG=ON, DEBUG_LEVEL=none.
  iOS inherits CMake defaults (ENABLE_RUNTIME_DEBUG=ON for Release,
  DEBUG_LEVEL=all for Debug) via Options.cmake build-type logic.

Generator
  macOS uses Unix Makefiles (make / cmake --build).
  iOS uses Xcode (required for Apple SDK cross-compilation).

Architectures
  iOS Simulator: fat binary (arm64 + x86_64).
  iOS Device:    arm64 only.
  macOS:         host architecture (determined at configure time).
