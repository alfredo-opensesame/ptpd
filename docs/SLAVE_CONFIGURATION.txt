Notes
================================================================================

1. PTPD_OPENSESAME_PORTS (10319/10320) is the build default for all ptpd
   targets. Define PTPD_STANDARD_PORTS at compile time to revert to 319/320.

2. The grandmaster uses nftables NAT to remap ports externally so that ptp4l
   (which hardcodes 319/320) communicates on 10319/10320. All slaves must use
   the same wire ports.

3. Hardware timestamping on rpi5-1 requires HWTSTAMP_FILTER_ALL because
   Delay_Req arrives at the NIC on port 10319 (before PREROUTING redirect).
   The filter is applied post-startup via ptp-gm-flags.service.

4. The macOS general PCAP filter must NOT restrict to multicast host addresses.
   On this network the grandmaster sends Delay_Resp to 224.0.1.129:10320
   (multicast). A host restriction of "224.0.x.x" would also work, but
   "udp port 10320" is used for simplicity and to handle any future unicast
   Delay_Resp without code changes.
